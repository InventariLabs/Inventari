# Groups are assigned per REACHABLE MECHANISM, not per directory — a
# sentence in app/core/contracts reaches a client through the 422 validator

#
# 1. client-400 — raised inside request handling; the global 400 handler
#    maps it to a client toast (app/modules, app/services, app/api). Pending

# 2. client-422 — Pydantic validator refusals reaching the client through
#    the 422 RequestValidationError envelope, a different path than the 400

#    Raw English here is real, tracked debt of the 422 class.
# 3. client-guards — core guards that fire during requests (imports,

# 4. boot-cli — raised while the process boots, a manage.py command runs or
#    a manifest/seed profile is validated; no client reads the toast.
# 5. internal-invariant — a guard on a caller's mistake or on a model's
#    malformed answer; no request supplies the value. Plain on purpose: the
#    400 handler logs a plain ValueError with its traceback. Assigned per
#    entry in REJECTION_GROUP_OVERRIDES, never by path.
#
