# Audit coverage allowlist — write paths that do not journal, by design
# Format: app-relative/path.py::qualname | <reason>
#
# Every mutating route and every CoreAPI namespace write method must reach
# log_action_async in its own module or in Core. The paths below do not, and
# rightly: login runs before a session exists, a working note is nobody's
# record but its author's, an outbox row is how an act is delivered rather
# than the act. docs/subsystems/AUDIT.md ("What earns an entry") and the
# AuditTargetType docstring are the rule each reason answers to.
#
# No owner and no date: a decision that is right by design does not lapse on
# a day. Adding a line is the decision, made in a diff with its reason beside
# it, and the size ratchet (baseline_sizes.txt) shows the gate covering less.
# A path that should journal and does not yet is debt, and debt goes in
# audit_coverage_baseline.txt with an owner and a date — never here.
