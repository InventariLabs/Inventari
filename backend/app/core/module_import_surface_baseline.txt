# Module import-surface baseline
#
# A module reaches Core through three paths: app.core.module_sdk (registration,
# hooks, interceptors, contributions, exceptions, dependencies, logging, the
# model base, pagination), app.core.contracts (DTOs) and app.core.public_api
# (data). The install-time safety scan allows a module installed from outside
# this repository nothing else. The modules the repository ships were written
# before that door existed, so each still imports core helpers directly; this
# file freezes what each one reaches as it stands.
#
# A shipped module also reaches another module's public API — the
# <name>_api / exceptions / schemas doors. That is the one cross-module door
# this tree allows, but it is still an exception to the same surface, so it
# is frozen here too: a new sibling dependency needs a written decision even
# when the cross-module shape gate would admit it.
#
# Format, one block per module:
#
#   <module> | owner=<who> | expires=<YYYY-MM-DD> | <reason>
#     <app path>
#     <app path>
#
# The check fails on a path that is not listed under its module, on a module
# without a block, on an entry whose import is gone (the list only shrinks),
# and on an expired block. Moving an import to the SDK is the way a path
# leaves this file — an additive change the SDK snapshot covers.
