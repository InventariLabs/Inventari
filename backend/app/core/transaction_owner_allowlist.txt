# Transaction owner allowlist
# Format: relative/path.py::qualname
#
# Functions that OWN their transaction: they hold a session no caller
# shared with them, so committing or rolling back inside them is the
# convention, not a violation. The transaction-ownership gate stays
# silent inside these functions, whatever the session is called and
# however many times they commit.
#
# This is a positive grant, not debt: it does not ride the baseline
# ratchet, and a new legal owner (a background job, a module router
# holding its own session, a CLI entry point, a session wrapper, a test
# helper) belongs here — never in transaction_ownership_baseline.txt.
# Keep entries at function granularity; a commit in a nested helper is
# not covered by its outer function's entry.
