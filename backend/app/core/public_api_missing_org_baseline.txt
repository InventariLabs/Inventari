# Baseline — public_api methods addressed by a row identifier that take
# no organization_id. Isolation for these rests on the calling module passing
# an id from its own organization (confused deputy).
#
# Empty: every method either carries the tenant (an organization_id, an
# OrganizationDTO or a UserContextDTO parameter), opts out in its signature
# (include_global, a _for_user suffix), or says at the method why it needs no
# organization — @without_org_scope('<reason>'), see public_api/_scope.py.
# A new entry here would mean a new method shipped without an org, which is
# exactly what the rule exists to stop: fix the method, do not list it.
#
