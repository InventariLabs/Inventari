## 6. Trivial Contributions

**Trivial contributions** are minor changes that carry no creative or intellectual property significance and therefore **do not require signing this Agreement**.

A contribution qualifies as trivial if it is limited to any of the following:

- Fixing a typo, grammar mistake, or punctuation in documentation or code comments.
- Correcting whitespace, indentation, or line endings.
- Updating a URL, fixing a broken link, or correcting a version number.
- Fixing an obvious one-line bug where no design decision is involved.
- Correcting an existing translation string (without adding new strings).

**How to ask for the waiver:** Say in your pull request that you consider the contribution trivial. Whether it is trivial is the Maintainer's decision. If the Maintainer agrees, they apply the `cla: trivial` label to the pull request and the CLA bot stops requiring a signature for it. Contributors cannot apply this label themselves, and nothing in the pull request's title or description waives the requirement.

The waiver covers the commits the Maintainer reviewed. When new commits are pushed to the pull request, or it is reopened, the CLA bot removes the label and requires a signature again until the Maintainer decides anew. The Maintainer may also remove the label and request a full signature at any time before the contribution is merged.
